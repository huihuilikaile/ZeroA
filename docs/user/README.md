## 30 秒上手

1. 确认本机有 **Node.js ≥ 22.19**（`node --version`）。
2. 双击 `zeroa.exe`。
3. `设置 → 模型`：选提供商、填 API 密钥、保存。
4. 左栏「工作区」→ **＋** 新建会话；输入框左下角选角色（如「CTF 竞赛」）。
5. 发一句：`用 bash 执行 uname -s 并告诉我结果` —— 看到工具卡片就说明整条链路通了。

> 只在**已授权**的 CTF 比赛、靶场或自有资产上使用。
> 密钥、Flag、比赛附件不要提交到公开仓库。
